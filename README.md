# Shader_100 — DirectX 12 グラフィックス 100本ノック

DirectX 12 と C++ で、描画の基礎から1ステップずつ積み上げていく学習リポジトリです。
1ノック = 1フォルダで、それぞれが単体でビルド・実行できる Visual Studio プロジェクトになっています。
最終目標は、海洋レンダリングやレイトレーシングを組み込んだ自作ゲームエンジンです。

## 動作環境

- Windows 10 / 11（DirectX 12 対応 GPU）
- Visual Studio 2022（プラットフォームツールセット v143、x64）
- Windows SDK 10
- シェーダモデル 5.1（Visual Studio の HLSL コンパイラでビルド時にコンパイル）

## 使用ライブラリ

| ライブラリ | 用途 | 導入方法 |
|------------|------|----------|
| [DirectXTK12](https://github.com/microsoft/DirectXTK12) | テクスチャの読み込み・GPU への転送（008〜） | NuGet（`packages.config`） |
| [Dear ImGui](https://github.com/ocornut/imgui) | 実行中にパラメータを変える Inspector（008〜） | ソースを `imgui/` に同梱 |
| [Assimp](https://github.com/assimp/assimp) | 3D モデルの読み込み（009〜） | vcpkg マニフェストモード（`vcpkg.json`） |

## ビルド方法

1. 見たいノックのフォルダにある `project/Last.sln` を Visual Studio 2022 で開く
2. 構成を **Debug / x64** にする
3. 009 以降は vcpkg が必要（初回のみ `vcpkg integrate install` を実行しておく）
4. ビルドして実行（F5）。NuGet・vcpkg のパッケージは初回ビルド時に自動で復元される
