## やったこと
- インデックスバッファ（頂点4個・インデックス6個）で描いた四角形を、時間に合わせて左右に往復させた
- 定数バッファを効率良く用いるためにWorld行列とそれ以外の座標変換行列の管理を分けるために,ディスクリプタヒープのNumdescriptorsの数を増やす.
- これを行うことでそれぞれのオブジェクトの移動を行う際に頂点情報が必要なく,World行列の書き換えのみで良くなる.

## 学んだこと
- 定数バッファには6種類あり,それぞれObjectCB,CameraCB,MaterialCB,LightCB,FrameCB,EffectCBの6種類が定数バッファとして扱うことができる.
- ## CBV（Constant Buffer View）

| 種類 | 格納するデータ | 何に使うのか |
|---|---|---|
| ObjectCB(今回使うもの) | World行列 | 物体の位置・回転・拡大縮小 |
| CameraCB(今回使うもの) | View行列, Projection行列, カメラ位置 | 3D空間を画面に映す |
| MaterialCB | 色, 金属度, 粗さ, 透明度 | 物体の材質や見た目を決める |
| LightCB | 光源位置, 光の方向, 色, 強度 | ライティング計算 |
| FrameCB | 経過時間, 画面サイズ | アニメーションや画面効果 |
| EffectCB | ぼかし強度, 波の高さ, 波の速さ | ポストエフェクトや水面表現 |
- また,これらの定数バッファが入るのはディスクリプタヒープの中であり,このディスクリプタヒープのTypeはCBV_SRV_UBVであるため,CBV以外の要素も入る.
- 頂点シェーダーで変換したとしても、CPUから渡された頂点データのオリジナル自体はそのまま毎フレーム同じ形で計算に使われる
