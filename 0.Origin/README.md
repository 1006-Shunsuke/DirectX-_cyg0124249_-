# 000 出発点（回転する三角形）

- 参考文献の Pocol『Direct3D 12 ゲームグラフィックス実践ガイド』を見ながら作った、最初の DirectX 12 のプログラム。001 以降はすべて、このコードを元にしている。
- 三角形を1枚、Y 軸まわりに回転させて描く。

## 手法
### 初期化の流れ
- `InitWnd` でウィンドウを作り、`InitD3D` で Direct3D 12 を使う準備をする。
  1. デバイス
  2. コマンドキュー
  3. スワップチェーン（DXGI Factory から作る）
  4. コマンドアロケータとコマンドリスト
  5. レンダーターゲットビュー（RTV）用のディスクリプタヒープ
  6. フェンス（CPU と GPU の同期に使う）
- `OnInit` で描画に使う GPU リソースを、次の順番に作る。
  1. 頂点バッファ（頂点3個。位置と頂点カラー）
  2. 定数バッファ（World / View / Proj 行列。フレームごとに1つずつ）
  3. ルートシグニチャ（定数バッファをルート CBV で渡す）
  4. パイプラインステート（シェーダ・入力レイアウト・ラスタライザ・ブレンドの設定）
  5. ビューポートとシザー矩形

### 毎フレームの処理
- リソースバリアでバックバッファを「表示用」から「描画用」に切り替え、灰色でクリアする。
- 回転角を `0.025f` ずつ増やし、`XMMatrixRotationY` で作った World 行列を今のフレームの定数バッファに書き込む。
- `DrawInstanced(3, 1, 0, 0)` で三角形を描き、バリアで「表示用」に戻して `Present` する。

## この章で新しく学んだこと
- DirectX 12 では、デバイス・コマンドキュー・スワップチェーン・コマンドリスト・ディスクリプタヒープ・フェンスを、すべて自分で用意しないと1枚も描けない。
- GPU への命令はコマンドリストに記録し、コマンドキューに渡して初めて実行される。
- バックバッファは「表示用」と「描画用」の状態をリソースバリアで切り替えてから使う。
