# 001 背景色を時間で変える

## 手法
- 経過時間を測る `Timer` クラスを作った。
  - `QueryPerformanceFrequency` で「1秒間に何回カウントするか（周波数）」を取得する。
  - 毎フレーム `QueryPerformanceCounter` で今のカウントを取り、前のフレームとの差を周波数で割って秒にする（`GetDeltaTime`）。
  - その秒を足していき、起動からの経過時間にする（`GetTotalTime`）。
- 背景（レンダーターゲット）をクリアする色を、`0.5 + 0.5 × sin(経過時間)` で時間とともに変えた。

## この章で新しく学んだこと
- QPC（`QueryPerformanceCounter`）の周波数とカウントを取り違えると、時間がほぼ進まない。
- フレームごとの経過時間（デルタタイム）を使うと、フレームレートが変わっても同じ速さで動かせる。
