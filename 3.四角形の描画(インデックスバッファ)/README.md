# 002 頂点6個で四角形を描く

## やったこと
- 三角形2枚（頂点6個）で四角形を描いた（左下が青、右上が赤）
- 描く頂点の数を `m_VertexCount = _countof(vertices)` で覚え、`DrawInstanced(m_VertexCount, 1, 0, 0)` で描くようにした
- 回転をやめて、World 行列を単位行列のままにした

## 学んだこと
- `DrawInstanced` の第1引数は「描く頂点の数」。頂点バッファを増やしても、ここを変えないと先頭の3個しか描かれない
- View / Proj行列を通しているので、横長のウィンドウでも正方形は潰れない

## 詰まったこと
- 直したはずのコードがディスクに保存されておらず、古い App.cpp からビルドされ続けていた
  → ファイルの中身を直接確かめて解決。「直したのに変わらない」時は、まず保存とビルド元を疑う
