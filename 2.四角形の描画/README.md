## 手法
### 1. 頂点6個で四角形を描く
- 三角形2枚（頂点6個）で四角形を描いた（左下が青、右上が赤）。
- 描く頂点の数を `m_VertexCount = _countof(vertices)` で覚え、`DrawInstanced(m_VertexCount, 1, 0, 0)` で描く。
- 回転をやめて、World 行列は単位行列のままにした。

### 2. インデックスバッファで頂点を使い回す
- 四角形の角は4つしかないのに、頂点6個では2つの頂点が重複している。
- そこで頂点を4個にし、「どの頂点をどの順で結ぶか」をインデックス `{ 0,1,2, 0,2,3 }` で指定した。
- インデックスバッファを UPLOAD ヒープに作り、ビュー（`D3D12_INDEX_BUFFER_VIEW`）に GPU アドレス・サイズ・形式（`DXGI_FORMAT_R32_UINT`）を設定した。
- 描画は `IASetIndexBuffer` でビューを設定し、`DrawIndexedInstanced(m_IndexCount, 1, 0, 0, 0)` で行う。

## 前と比べてできるようになったこと
- 三角形だけでなく、四角形を描けるようになった。
- インデックスバッファで頂点を使い回せるようになった（頂点6個 → 頂点4個＋インデックス6個）。

## この章で新しく学んだこと
- `DrawInstanced` の第1引数は「描く頂点の数」。頂点バッファを増やしても、ここを変えないと先頭の3個しか描かれない。
- View / Proj 行列を通しているので、横長のウィンドウでも正方形は潰れない。
- インデックスバッファを使うと、同じ頂点を何度も書かずに済む。頂点の数が多いモデルほど、メモリと頂点シェーダの処理が減る。
- インデックスバッファのビューには、ストライドの代わりに「インデックス1個の形式」（`R16_UINT` か `R32_UINT`）を設定する。
